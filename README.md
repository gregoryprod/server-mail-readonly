# Как подключить почту Materlux к агенту на Mac?

Автономный Ruby-скрипт для чтения `order@materlux.ru` по IMAP и инструкция для AI-агента.
Пароля, ключей доступа и выгрузок писем в репозитории нет.

Скачай репозиторий через **Code → Download ZIP** и распакуй его или выполни:

```sh
git clone https://github.com/gregoryprod/materlux-imap-readonly.git
```

Передай агенту [AGENT.md](AGENT.md) вместе с [read_mail.rb](read_mail.rb)
и попроси настроить подключение по инструкции на своём компьютере.
Сотрудник самостоятельно один раз сохраняет пароль в macOS Keychain.
Нужны разрешение владельца ящика, пароль и подходящее Ruby-окружение.
Точные зависимости и проверка без повторного ввода пароля описаны в инструкции.

Клиент читает через EXAMINE и BODY.PEEK[]; не отправляет и не изменяет письма.
Сам пароль может иметь более широкие права в другом клиенте.
Для этого сервера сохранено разрешённое владельцем исключение срока конечного
сертификата; остальные проверки TLS включены. Опция `--strict-certificate`
включает проверку срока после исправления сертификата администратором.

Проверено на macOS с Ruby 3.3.0 и net-imap 0.6.8. Новый компьютер требует
однократной настройки и проверки по инструкции. Постоянный доступ на Windows/Linux
не заявлен. Подключение не включает CRM, автозапуск или отправку сообщений.

Не добавляй в репозиторий пароль, .env или частные выгрузки `exports/`.
