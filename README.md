# Как подключить агенту почту на сервере?

Универсальный Ruby-клиент для чтения почтового ящика по **IMAP over TLS**.
Сервер, порт и логин задаются при настройке; привязки к компании или ящику нет.

- **Windows x64:** пароль защищён штатным DPAPI текущего пользователя.
- **macOS:** пароль хранится в Связке ключей.
- **Linux:** доступен ручной скрытый ввод, без постоянного хранилища пароля.

Скачай **Code → Download ZIP** или:

```sh
git clone https://github.com/gregoryprod/server-mail-readonly.git
```

Передай агенту [инструкцию AGENT.md](AGENT.md) и [скрипт read_mail.rb](read_mail.rb).
В инструкции есть отдельные команды PowerShell и macOS: подготовка Ruby,
однократная настройка и проверка работы без повторного ввода пароля.
Нужен разрешённый доступ к ящику, адрес IMAP-сервера, TLS-порт, логин и пароль.
Пароль вводится владельцем в его терминале, а не в чате агента.

Клиент использует EXAMINE/BODY.PEEK[], не меняет и не отправляет письма.
Сам пароль может иметь более широкие права в другом клиенте.
Сертификаты проверяются строго; просроченный конечный сертификат допускается
только отдельной опцией по решению владельца. POP3, STARTTLS и OAuth-only не реализованы.
В репозитории нет рабочих настроек, паролей или писем.

Проверочный профиль: Ruby 3.3, net-imap 0.6.8; Windows x64 и macOS.
[Автотесты](https://github.com/gregoryprod/server-mail-readonly/actions) используют
синтетические данные. На Windows выполняется настоящий DPAPI round-trip.
Реальное подключение и интерактивный ввод на конкретном компьютере проверяются
после установки по инструкции. Наличие программы не доказывает доступ к ящику.

Для разработки: `ruby test/read_mail_test.rb` (нужен minitest).
Пользователю тестовый runtime не нужен.
